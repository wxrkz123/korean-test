# TOPIK 刷题本

TOPIK II 阅读（읽기）真题刷题网页，收录第 35、37、41、47、52、64、83、91、96、102 回，共 10 回 500 题；另有写作（쓰기）51–54 题练习。

- **依次刷题**：按年份顺序（第35回 → 第102回）作答，每回做完显示成绩并进入下一回；首页的“继续”会回到你最近在做的那一回。选完选项立即判对错。
- **悬停查词**：鼠标放在任何韩语单词上（手机上点一下）显示中文释义、原形、相关语法（如 `-(으)ㄹ 만큼`）和惯用表达（如 `발 벗고 나서다`），并附 Naver 韩中词典链接。
- **生词本**：在弹窗里点“☆ 生词本”收藏单词 / 语法 / 惯用表达，连同出处原句一起保存；收藏过的词在题目里用黄色标出。支持“遮住中文自测”和“复制全部”（可粘贴到 Excel / Anki）。
- **错题本**：答错的题自动收录，可一键重做。
- **答题卡**：侧边 1–50 题号格子，显示对 / 错 / 未答。键盘 `1`–`4` 作答，`←` `→` 翻题。
- **中文翻译与解析**：每题右上角“显示中文翻译”按钮（快捷键 `T`）可在每段韩文和选项下显示中文；作答后显示解析；第30–50题另有详细解析（解题思路、原文关键句、逐项分析、重点词汇）。

- **写作练习**（导航栏“写作”）：
  - 第35、37、64、83、91、96回写作真题 51–54 题，共 24 题；第53题的图表直接取自原卷。
  - 每题直接显示参考答案（51/52 填在文章空格里）或范文、中文翻译、解析和关键表达，不需要先作答。
  - 想动笔时展开“自己练习写一遍”：53/54 有字数统计（含空格）和原稿纸预览，54 题可以先列提纲，写的内容自动保存。
- **AI 批改**：在 claude.ai 里打开本页时，写作题可以点“AI 批改”，由 Claude 按 TOPIK 评分标准估分、逐句修改并给出修改后的全文（使用打开者自己的 Claude 用量）。GitHub Pages 上没有这个功能，只能对照参考答案自查。

进度、生词本、写作草稿和 AI 批改结果保存在浏览器 localStorage 里；作为 claude.ai Artifact 打开时，还会私密同步到你自己的账号。

## 打开方式

这是纯静态网页，需要通过 HTTP 打开（直接双击 `index.html` 时浏览器会禁止读取题库文件）：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。也可以在仓库 Settings → Pages 里选择这个分支的根目录，用 GitHub Pages 发布。

## 目录

| 路径 | 内容 |
| --- | --- |
| `index.html` | 网页（样式和脚本都在里面） |
| `data/` | 构建好的题目与词典数据（`e64.json` 等每回一个文件，`dict.json` 为词典） |
| `img/` | 第10题的图表 |
| `source/tpk/*.tpk` | 每回题目的文字稿（题干、选项、答案），可直接编辑 |
| `source/gloss.json` | 原 PDF 页边的中文生词注释（约 1700 条，来自第64–102回的注释版 PDF） |
| `source/translations.tsv` | 补充的韩中释义（约 3500 条） |
| `source/zh/` | 中文翻译与解析：`common.tsv` 是共用的题目说明，`35.zh` 等每回一个文件 |
| `source/write/` | 写作真题：`51.wr`–`54.wr` 题目与参考答案，`guide.wr` 题型攻略（第53题图表图片在 `img/w*-53.png`） |
| `tools/` | 构建脚本：`build.py`、写作数据 `writebuild.py`、语法句型表 `grammar.py`、题目文件解析 `tpk.py` |

修改题目、答案或释义后重新生成数据：

```bash
pip install kiwipiepy
python3 tools/build.py
```

`.zh` 格式：`=== 起-止` 后的 `P:` 行依次对应题组文章的每一段；`## n` 后 `T:` 对应题干段落，`B:` 方框句，`S:` 广告/通知每行，`O:` 四个选项用 ` | ` 分隔，`E:` 解析，`Q:`（可选）小题题干。构建时会检查段落数是否对得上。

`.exp` 格式（30–50题的详细解析）：`## n` 后每行一条，`思路：`、`关键句：`、`词汇：` 开头的行显示为带标题的段落，`①○`/`②×` 开头的行是逐项分析（○ 为正确选项）。「」里的韩文必须与原文一致（中间可用 … 省略），构建时会检查引文和 ○ 选项是否与答案一致。

`.wr` 格式（写作题）：`=== 51-37` 开始一题（以后加入其他回的真题时，按 `题号-回数` 命名）；`S:` 来源，`H:`/`HZ:` 韩/中标题，`I:`/`IZ:` 题目说明，`K:`/`KZ:` 题目每一行及其中文（`K: # …` 标题行，`K: ^ …` 留言板名称等小字，`K: > …` 对方发来的短信；第53题用 `K:` 抄录图表里的文字，方便查词），`G:` 第53题图表图片，`L:`/`LZ:` 54 题的提问，`C:` 53 题图表（一行 JSON，`CZ:` 中文说明），`A:`/`AZ:` 51/52 题㉠㉡的答案（多个写法用 ` | ` 分隔），`M:`/`MZ:` 范文段落，`N:` 解析，`X:` 关键表达 `韩文 | 中文`。构建时检查每行都有中文、53/54 范文字数在 200–300 / 600–700 之间、解析里「」引用的韩文出自题目或范文。文件开头的注释说明了图表 JSON 的写法。

`.tpk` 格式：`=== 起-止` 是题组和说明，`>>>` … `<<<` 是题组共用的文章，`## n` 是题号，`? ` 开头是小题题干，`[box]` 是方框句子，`[poster]` … `[/poster]` 是广告/通知，`[img] 64-10` 是图片，`1)`–`4)` 是选项，`= n` 是答案，`__…__` 是下划线。

## 说明

- 第64、83、91、102回的题目文字由扫描 PDF 识别后逐页人工校对；第96回和第35、37、41、47、52回直接取自 PDF 文字层，再对照原卷修正断行、下划线和广告/通知内容。第37回的 PDF 同时包含听力和写作，阅读部分收在刷题里，写作 51–54 题收在写作练习里；第35、64、83、91、96回的写作题来自另外上传的 1교시（듣기·쓰기）试卷（听力未收录）。
- **答案不是官方答案表**：官方答案在当前环境下无法下载，答案是逐题解答并复核的结果。发现有误可以改对应 `.tpk` 里的 `= n` 后重新构建。
- 第96回 42–43 题、第102回 23–24、42–43 题，原卷因版权原因未公开文章，网页中显示提示，不计分。
- 释义优先使用原 PDF 页边的注释，其余由补充词表提供；词形分析使用 [Kiwi](https://github.com/bab2min/kiwipiepy)。
- 写作的参考答案和范文是自己写的，不是官方答案。
