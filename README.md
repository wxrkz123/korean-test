# TOPIK 阅读刷题本

TOPIK II 阅读（읽기）真题刷题网页，收录第 35、37、41、47、52、64、83、91、96、102 回，共 10 回 500 题。

- **依次刷题**：按年份顺序（第35回 → 第102回）作答，每回做完显示成绩并进入下一回；首页的“继续”会回到你最近在做的那一回。选完选项立即判对错。
- **悬停查词**：鼠标放在任何韩语单词上（手机上点一下）显示中文释义、原形、相关语法（如 `-(으)ㄹ 만큼`）和惯用表达（如 `발 벗고 나서다`），并附 Naver 韩中词典链接。
- **生词本**：在弹窗里点“☆ 生词本”收藏单词 / 语法 / 惯用表达，连同出处原句一起保存；收藏过的词在题目里用黄色标出。支持“遮住中文自测”和“复制全部”（可粘贴到 Excel / Anki）。
- **错题本**：答错的题自动收录，可一键重做。
- **答题卡**：侧边 1–50 题号格子，显示对 / 错 / 未答。键盘 `1`–`4` 作答，`←` `→` 翻题。

进度和生词本保存在浏览器 localStorage 里；作为 claude.ai Artifact 打开时，还会私密同步到你自己的账号。

## 打开方式

这是纯静态网页，需要通过 HTTP 打开（直接双击 `index.html` 时浏览器会禁止读取题库文件）：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。也可以在仓库 Settings → Pages 里选择这个分支的根目录，用 GitHub Pages 发布。

## 目录

| 路径 | 内容 |
| --- | --- |
| `index.html` | 网页（样式和脚本都在里面） |
| `data/` | 构建好的题目与词典数据（`e64.json` 等每回一个文件，`dict.json` 为词典） |
| `img/` | 第10题的图表 |
| `source/tpk/*.tpk` | 每回题目的文字稿（题干、选项、答案），可直接编辑 |
| `source/gloss.json` | 原 PDF 页边的中文生词注释（约 1700 条，来自第64–102回的注释版 PDF） |
| `source/translations.tsv` | 补充的韩中释义（约 3500 条） |
| `tools/` | 构建脚本：`build.py`、语法句型表 `grammar.py`、题目文件解析 `tpk.py` |

修改题目、答案或释义后重新生成数据：

```bash
pip install kiwipiepy
python3 tools/build.py
```

`.tpk` 格式：`=== 起-止` 是题组和说明，`>>>` … `<<<` 是题组共用的文章，`## n` 是题号，`? ` 开头是小题题干，`[box]` 是方框句子，`[poster]` … `[/poster]` 是广告/通知，`[img] 64-10` 是图片，`1)`–`4)` 是选项，`= n` 是答案，`__…__` 是下划线。

## 说明

- 第64、83、91、102回的题目文字由扫描 PDF 识别后逐页人工校对；第96回和第35、37、41、47、52回直接取自 PDF 文字层，再对照原卷修正断行、下划线和广告/通知内容。第37回的 PDF 同时包含听力和写作，这里只收录阅读部分。
- **答案不是官方答案表**：官方答案在当前环境下无法下载，答案是逐题解答并复核的结果。发现有误可以改对应 `.tpk` 里的 `= n` 后重新构建。
- 第96回 42–43 题、第102回 23–24、42–43 题，原卷因版权原因未公开文章，网页中显示提示，不计分。
- 释义优先使用原 PDF 页边的注释，其余由补充词表提供；词形分析使用 [Kiwi](https://github.com/bab2min/kiwipiepy)。
